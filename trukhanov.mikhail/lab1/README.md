# Лабораторная работа 1

## Задание

Вариант 4

Создать таблицу с данными о продажах за месяц. Таблица должна иметь три
столбца - "Продукт", "Продано", "Выручка" и пять рядов с данными. В футере
таблицы необходимо отобразить общую сумму проданных товаров и общую выручку. При
создании таблицы необходимо использовать соответствующие семантические теги -
`<thead>`, `<tbody>`, `<tfoot>` и другие. Фон у четных строк должен быть
светло-серым (#f2f2f2), а у нечетных — белым (#ffffff). Ряд таблицы при
наведении курсора должен выделяться более темным серым цветом (#d3d3d3).

## Реализация

Страница index.html содержит таблицу с данными о продажах за месяц, которая
имеет три столбца - "Продукт", "Продано", "Выручка" и пять рядов с данными. В
футере таблицы отображены общая сумма проданных товаров и общая выручка.

В файле styles.css задан границы таблицы, фон строк, а также изменение цвета
ряда при наведении курсора.

## Запуск

Откройте `index.html` в браузере.
