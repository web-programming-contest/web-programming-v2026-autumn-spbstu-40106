# Лабораторная работа 3

## Задание

Вариант 4

Реализуйте функцию mergeArrays(arr1, arr2), которая объединяет два массива,
удаляя дубликаты.

## Реализация

Функция реализована при помощи оператора spread для объединения массивов и
преобразования к Set для удаления дубликатов. Полученное множество преобразуется
обратно в массив с помощью оператора spread.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
