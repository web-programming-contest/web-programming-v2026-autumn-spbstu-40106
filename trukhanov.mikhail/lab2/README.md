# Лабораторная работа 2

## Задание

Вариант 4

Написать функцию convertBase(num, fromBase, toBase), преобразующую число между
системами счисления.

## Реализация

Функция convertBase принимает на вход число num в системе счисления fromBase и
преобразует его в систему счисления toBase. Алгоритм реализован с использованием
встроенных средств JavaScript: функция parseInt преобразует исходное число в
десятичную систему счисления, a метод toString преобразует десятичное число в
нужную систему счисления.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
