# Лабораторная работа 1

## Задание

Вариант 4. Создать таблицу с данными о продажах за месяц. Таблица должна иметь
три столбца — «Продукт», «Продано», «Выручка» и пять рядов с данными. В футере
таблицы необходимо отобразить общую сумму проданных товаров и общую выручку.

## Реализация

Для решения использованы семантические теги таблицы:

- `<table>` — основная таблица
- `<thead>` — шапка таблицы с названиями столбцов
- `<tbody>` — тело таблицы с пятью строками данных
- `<tfoot>` — подвал таблицы с итоговыми суммами

Стилизация выполнена в файле `styles.css`. Чётные строки имеют фон `#f2f2f2`,
нечётные строки - `#fff`. Ряд таблицы при наведении курсора выделяются более
темным серым цветом `#d3d3d3`. Шапка и подвал таблицы имеют тёмный фон
`#2d2d2d`, текст в ячейках выделен белым цветом.

## Запуск

Открыть файл `index.html` в браузере.
