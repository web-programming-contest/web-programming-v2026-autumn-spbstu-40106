# Лабораторная работа 4

## Задание

Вариант 4. Класс `Order` с полями `orderId` (число), `items` (массив товаров
`{ name, price }`), `status` (строка). Методы: `addItem(item)`,
`removeItem(name)`, `getTotal()`. Пять функций для работы с коллекцией:
`groupOrdersByStatus`, `getUniqueItems`, `groupOrdersByTotal`,
`findOrdersByItem`, `findOrdersByStatus`. Пользовательский интерфейс: список
карточек заказов, формы добавления заказа и товара, удаление заказа и товара,
изменение статуса через выпадающий список, сохранение в `localStorage`.

## Реализация

В файле `model.js` экспортируется класс `Order` и пять функций. Класс `Order`
описывает заказ и содержит все требуемые поля, а также методы `addItem` для
добавления товара, `removeItem` для удаления товара по имени и `getTotal` для
подсчёта суммы всех товаров. Функция `groupOrdersByStatus` группирует заказы по
статусу, `getUniqueItems` возвращает уникальный список товаров,
`groupOrdersByTotal` группирует заказы по диапазонам суммы, `findOrdersByItem`
возвращает заказы, содержащие указанный товар, а `findOrdersByStatus` возвращает
заказы по заданному статусу. В main.js реализована логика интерфейса. Создание
карточек заказов, добавление заказа через форму, добавление и удаление товара в
карточке заказа, изменение статуса через выпадающий список, удаление заказа. Все
операции выполняются асинхронно через `Promise` и `setTimeout`, состояние
сохраняется в `localStorage`.

## Запуск

Откройте `index.html` через локальный HTTP-сервер (например, расширение Live
Server в VS Code).
