# Лабораторная работа 2

## Задание

Вариант 4. Написать функцию convertBase(num, fromBase, toBase), преобразующую
число между системами счисления. Проверяются распространённые основания 2, 8, 10
и 16. Регистр HEX-цифр не важен.

## Реализация

Функция экспортируется под именем `convertBase`. Входная строка парсится в
десятичное число с помощью функции`parseInt(num, fromBase)`, которой передаётся
число и исходная система счисления. Затем десятичное число переводится в систему
счисления `toBase` методом toString.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
