# Лабораторная работа 5

## Задание

Вариант 4. Реализовать механику рейтинга в книжном интернет-магазине. Создать
список книг, который содержит обложку, название, рейтинг, описание и цену. В
каждом компоненте книги добавить возможность выставлять рейтинг пользователем.
Рейтинг рассчитывается как средняя оценка (сумма оценок, делённая на их
количество). Компонент рейтинга принимает количество звёзд (по умолчанию 5) и
рейтинг (число), а также позволяет пользователю изменить рейтинг: после
голосования на 3–4 секунды отображается выбранная пользователем оценка, затем
возвращается среднее значение.

## Реализация

Приложение реализовано на React с использованием Vite. Точка входа -
`src/main.jsx`, который рендерит компонент `App` в корневой элемент
`[data-testid="app"]`. Компонент `BookList` хранит массив книг с полями `id`,
`title`, `cover`, `rating`, `votes`, `description`, `price` и для каждой книги
создаёт компонент `Book`. Карточка книги имеет атрибут `data-testid="book-card"`
и отображает обложку, название, описание, цену и рейтинг.

Компонент `Rating` реализует механику голосования. В нём два состояния:
`userRating` (оценка пользователя, изначально `null`) и `displayRating` (текущее
отображаемое значение). При клике на звезду `userRating` меняется, `useEffect`
показывает его в `displayRating` и запускает `setTimeout` на 3.5 секунды. Через
это время оценка сбрасывается, и `displayRating` возвращается к среднему
рейтингу. Таймер очищается через `clearTimeout` при следующем клике.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
