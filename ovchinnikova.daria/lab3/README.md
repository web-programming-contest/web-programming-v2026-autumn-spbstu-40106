# Лабораторная работа 3

## Задание

Вариант 4. Реализуйте функцию mergeArrays(arr1, arr2), которая объединяет два
массива, удаляя дубликаты.

## Реализация

Функция экспортируется под именем `mergeArrays`. Создаётся новый массив `result`
для результата и множество `seen` для отслеживания уникальных элементов двух
входных массивов. В цикле объединяются два массива, проходимся по элементам
этого объединения, проверяем, если элемента нет в множестве, то добавляем его в
множество и массив `result`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
