# Лабораторная работа 1

## Задание

Вариант №27

Создать блок с текстом. Текст должен быть обрезан, если он превышает высоту 100
пикселей или 3 строки. Лишний текст должен скрываться и заменяться многоточием.
Шрифт текста - Arial, размер - 16px.

## Реализация

На странице создан текстовый блок с классом `text-block`.

Для блока заданы ширина 400px, максимальная высота 100px, шрифт Arial и размер
шрифта 16px. Для ограничения текста до трех строк используется
`-webkit-line-clamp`, а лишний текст скрывается с помощью `overflow: hidden`.

## Запуск

Откройте `index.html` в браузере.
