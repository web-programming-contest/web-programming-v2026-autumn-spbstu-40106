# Лабораторная работа 5

## Задание

Реализовать слайдер книг на главной странице книжного интернет-магазина с
использованием React.

Карточка книги должна содержать обложку, название, рейтинг и описание.
Необходимо реализовать переключение слайдов кнопками «Далее» и «Назад»,
отображение номера текущего слайда и общего количества слайдов, а также
пагинацию для перехода к выбранной книге.

## Реализация

Приложение реализовано на React с использованием JavaScript (JSX), CSS и Vite.

В слайдере представлены три книги. Каждая карточка содержит обложку, название,
автора, рейтинг, цену и описание.

Основные файлы проекта:

- `index.html` - HTML-страница с корневым элементом приложения.
- `src/main.jsx` - массив книг, компонент `App` и логика переключения слайдов.
- `src/styles.css` - оформление карточек, кнопок и адаптация под мобильные
  устройства.
- `assets` - локальные изображения обложек книг.

Для хранения индекса текущего слайда используется хук `useState`.

Функция `nextSlide` переключает на следующую книгу, а `previousSlide` - на
предыдущую. При достижении конца или начала списка переключение происходит по
кругу.

Пагинация создаётся с помощью метода `map()`. При нажатии на номер слайда
вызывается `setCurrentSlide`, который изменяет текущий слайд.

## Запуск

Для запуска приложения необходимо установить Node.js.

Перейти в папку `lab5` и установить зависимости:

```bash
npm install
```

Запустить приложение:

```bash
npm run dev
```

Открыть в браузере адрес, указанный в терминале, обычно
`http://localhost:5173/`.

Для проверки сборки выполнить:

```bash
npm run build
```
