# Лабораторная работа 2

## Задание

Вариант №27.

Написать функцию `toRoman(num)`, преобразующую целое число от 1 до 3999 в
стандартную римскую запись в верхнем регистре.

## Реализация

Функция `toRoman` экспортируется как именованный export. Число преобразуется в
римскую запись перебором значений от большего к меньшему. Подходящие римские
обозначения добавляются в результат, а соответствующие значения вычитаются из
исходного числа.

Функция работает с целыми числами от 1 до 3999, включая граничные значения.

## Запуск

Импортируйте именованный export `toRoman` из `solution.js` как ES module.
