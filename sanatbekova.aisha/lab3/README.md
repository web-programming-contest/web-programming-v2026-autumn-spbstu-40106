# Лабораторная работа 3

## Задание

Вариант №27.

Реализовать функцию `rotateArray(arr, steps)`, которая сдвигает массив вправо на
`steps` элементов.

## Реализация

Функция `rotateArray` экспортируется как именованный export.

Количество позиций сдвига вычисляется с учетом длины массива. Элементы с конца
массива переносятся в начало с помощью метода `slice`.

Если массив пустой, функция возвращает пустой массив. Если сдвиг равен нулю или
кратен длине массива, возвращается копия исходного массива.

Исходный массив не изменяется.

## Запуск

Импортируйте именованный export `rotateArray` из `solution.js` как ES module.
