# Лабораторная работа 4

## Задание

Вариант №27. Студенты и оценки.

Реализовать класс `Student` с полями `id`, `name` и `grades`.

Класс содержит методы:

- `addGrade(subject, grade)` - добавление или обновление оценки;
- `getAverageGrade()` - вычисление среднего балла;
- `summary` - информация о студенте.

Также реализованы функции:

- `groupStudentsByAverageGrade` - группировка студентов по среднему баллу;
- `getUniqueSubjects` - получение уникального списка предметов;
- `groupStudentsBySubject` - группировка студентов по предметам;
- `getTopStudents` - получение студентов с максимальным средним баллом;
- `findStudentsBySubject` - поиск студентов по предмету.

## Реализация

Интерфейс позволяет добавлять и удалять студентов, добавлять и удалять оценки.

Операции добавления и удаления выполняются асинхронно с использованием `Promise`
и `setTimeout`.

После изменений список студентов автоматически обновляется.

Данные сохраняются в `localStorage` и восстанавливаются после обновления
страницы.

## Запуск

Запустите локальный сервер и откройте `index.html` в браузере.
