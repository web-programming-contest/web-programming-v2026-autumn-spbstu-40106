# Лабораторная работа 4

## Задание

Вариант 5. Создать приложение для управления командами и их участниками.
Карточка команды показывает название, число участников и список их имён и ролей.
Команды и участники добавляются и удаляются асинхронно. Текущий список команд
сохраняется в браузере и восстанавливается при следующем открытии страницы.

## Реализация

Класс `Team` в `model.js` хранит название команды и массив участников.
`addMember` добавляет участника, `removeMember` удаляет по имени, а геттер
`memberCount` вычисляет число участников.

- `groupMembersByRole` группирует участников по ролям.
- `getUniqueRoles` возвращает массив уникальных ролей.
- `groupTeamsByMemberCount` группирует команды по числу участников.
- `findTeamsByMember` находит команды по имени участника.
- `getUniqueMembers` возвращает объекты участников без повторов по имени. Если
  имя встречается в нескольких командах, берётся первая запись.

Обе группировки возвращают `Map`. В интерфейсе имя должно быть уникальным в
пределах одной команды, поскольку удаление выполняется по имени. Модуль
`main.js` обрабатывает формы и кнопки. После задержки через `Promise` и
`setTimeout` он применяет изменение, обновляет DOM и записывает список команд в
`localStorage`. При загрузке из сохранённых данных снова создаются экземпляры
`Team`.

## Запуск

В корне репозитория запустите локальный HTTP-сервер (нужен Python 3):

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory dobrov.matvey/lab4
```

Откройте в браузере [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
