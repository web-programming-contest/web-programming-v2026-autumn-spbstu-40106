# Лабораторная работа 2

## Задание

Задача 2. Написать функцию `toBinary(num)`, преобразующую десятичное число в
двоичную строку без ведущих нулей.

## Реализация

Решение находится в ES-модуле `solution.js`. Функция `toBinary` доступна через
именованный экспорт и возвращает строку с помощью метода `num.toString(2)`.

Аргумент должен быть целым числом в безопасном диапазоне JavaScript
(`Number.MIN_SAFE_INTEGER` — `Number.MAX_SAFE_INTEGER`). Для остальных значений
выбрасывается `TypeError`. Ноль преобразуется в строку `'0'`, у отрицательных
чисел сохраняется знак минус: `toBinary(-5)` возвращает `'-101'`.

## Запуск

Для запуска необходим Node.js. Откройте терминал в папке с `solution.js` и
выполните:

```powershell
@(
  Get-Content -Raw .\solution.js
  'console.log(toBinary(10)); console.log(toBinary(5)); console.log(toBinary(0));'
) | node --input-type=module
```

Ожидаемый вывод:

```text
1010
101
0
```

Команда для PowerShell передаёт содержимое файла и примеры вызова в Node.js в
режиме ES-модуля. Сам `solution.js` только экспортирует функцию; для вывода
результата используется `console.log` в команде запуска.
