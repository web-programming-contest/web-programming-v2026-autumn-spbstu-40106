# Лабораторная работа 5

## Задание

Вариант 5. На React реализовать каталог книжного интернет-магазина в виде дерева
с четырьмя уровнями: автор, издательство, жанр, название книги. Ветки дерева
должны раскрываться и сворачиваться.

## Реализация

Демонстрационный каталог хранится в `src/books.js`. Компонент `BookTreeLevel`
группирует книги через `Map.groupBy` по полю текущего уровня и рекурсивно
выводит вложенные списки. На последнем уровне выводятся названия книг.

Ветки используют HTML-элементы `details` и `summary`. Браузер хранит состояние
раскрытия каждой ветки, поэтому переключение работает мышью и с клавиатуры. При
запуске раскрыта первая цепочка до книг. У приложения нет запросов к внешним
источникам.

## Запуск

Из корня репозитория:

```powershell
cd dobrov.matvey/lab5
npm install
npm run dev
```

Откройте в браузере адрес, который выведет Vite. Обычно это
[http://127.0.0.1:5173/](http://127.0.0.1:5173/). Для сборки выполните
`npm run build` в каталоге лабораторной.
