# Лабораторная работа 2

## Задание

Написать функцию `isPerfectNumber`, которая проверяет, является ли переданное
число "совершенным" (сумма его собственных делителей равна самому числу,
исключая само число).

## Реализация

Функция проверяет входное значение на корректность (целое положительное число
больше 1). Затем с помощью цикла находят все делители числа в диапазоне от 1 до
`n / 2`, вычисляется их сумма, и результат сравнивается с исходным числом.
Возвращается булево значение (`true` или `false`).

## Запуск

Импортируйте именованный export функции из файла `solution.js`:

```javascript
import {isPerfectNumber} from './solution.js';
```
