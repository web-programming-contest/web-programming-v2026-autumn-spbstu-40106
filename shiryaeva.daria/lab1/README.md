# Лабораторная работа 1

## Задание

Вариант 31. Создать каталог товаров, сгруппированных по категориям в виде
вложенных списков, с жирными названиями и ценами курсивом.

## Реализация

Использована семантическая разметка списков, стили вынесены в отдельный файл
styles.css с использованием классов `.product-name` и `.product-price`.

## Запуск

Откройте index.html в браузере.
