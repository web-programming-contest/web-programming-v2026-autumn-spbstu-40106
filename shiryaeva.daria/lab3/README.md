# Лабораторная работа 3

## Задание

Реализовать функцию `intersection(arr1, arr2)` для поиска общих элементов двух
массивов.

## Реализация

Функция преобразует `arr2` в `Set` для быстрого поиска за $O(1)$. С помощью
цикла `for...of` элементы `arr1` проверяются на наличие во множестве и
добавляются в результат без дубликатов.

## Запуск

Импорт функции из `solution.js`:

```javascript
import {intersection} from './solution.js';
```
