# Лабораторная работа 3

## Задание

**Вариант 20.** Реализовать функцию `slidingWindowSums(arr, k)`, которая
возвращает массив сумм всех последовательных окон длиной `k`.

## Реализация

Функция использует алгоритм скользящего окна. Сначала вычисляется сумма первых
`k` элементов массива.

При каждом следующем шаге из текущей суммы вычитается элемент, покидающий окно,
и прибавляется новый элемент.

Полученные суммы записываются в результирующий массив.

Алгоритм имеет временную сложность O(n).

## Запуск

Импортируйте именованный export `slidingWindowSums` из `solution.js` как ES
module.
