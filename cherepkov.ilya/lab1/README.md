# Лабораторная работа 1

## Задание

**Вариант 20.** Создать диалоговое окно, имитирующее окно подтверждения действия
(например, «Вы уверены?»).

Окно должно содержать:

- Заголовок «Подтверждение».
- Текст сообщения «Вы действительно хотите удалить этот файл?».
- Кнопки «OK» и «Отмена».

Окно должно быть центрировано на странице.

## Реализация

В HTML создано диалоговое окно с заголовком, текстом сообщения и двумя кнопками.

Для размещения окна по центру страницы используется CSS Flexbox.

Для всех элементов добавлены соответствующие стили. Настроены размеры окна,
внутренние отступы, цвет фона и закругление углов.

Кнопки «OK» и «Отмена» расположены горизонтально с помощью Flexbox.

Стили вынесены в отдельный файл `style.css`.

## Запуск

Откройте `index.html` в браузере.
