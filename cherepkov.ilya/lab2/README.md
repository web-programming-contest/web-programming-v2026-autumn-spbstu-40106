# Лабораторная работа 2

## Задание

**Вариант 20.** Написать функцию, которая преобразует RGB-строку (например,
`"rgb(255,0,0)"`) в HEX-формат.

## Реализация

Функция извлекает из RGB-строки три числовых значения с помощью регулярного
выражения. Каждое значение преобразуется в шестнадцатеричную систему счисления с
помощью `toString(16)`.

Метод `padStart()` добавляет ведущий ноль при необходимости. Полученные значения
объединяются в строку с символом `#` в начале и переводятся в верхний регистр.

## Запуск

Подключите `script.js` к HTML-файлу и откройте `index.html` в браузере.
Результат выполнения функции выводится в консоль браузера (F12).
