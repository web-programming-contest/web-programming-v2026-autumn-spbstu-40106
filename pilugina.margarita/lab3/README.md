# Лабораторная работа 3

## Задание

Вариант 15. Реализовать функцию `moveZerosToEnd(arr)`, которая перемещает все
нули в конец массива, сохраняя порядок остальных элементов.

## Реализация

- Реализован именованный ES-экспорт функции `moveZerosToEnd(arr)`.
- Все элементы массива перебираются последовательно.
- Нулевые элементы сохраняются отдельно от остальных элементов.
- Порядок ненулевых элементов сохраняется.
- После обработки массива нули добавляются в конец результата.
- Исходный массив не изменяется: функция возвращает новый массив.

## Запуск

Подключите функцию в модуль JavaScript:

```javascript
import {moveZerosToEnd} from './solution.js';

console.log(moveZerosToEnd([0, 2, 0, 3, 0, 6, 7]));
// [2, 3, 6, 7, 0, 0,0]
```
