# Лабораторная работа 2

## Задание

Вариант 15. Сделать функцию, которая принимает дату и возвращает строку с
описанием того, сколько времени прошло с этой даты (например, "5 минут назад",
"2 часа назад", "3 дня назад" и т.д.).

## Реализация

Функция `getTimeAgo` принимает дату в формате `Date` и определяет, сколько
времени прошло с этой даты до текущего момента.

Сначала с помощью `new Date()` определяется текущая дата и время. Затем
вычисляется разница между текущей датой и переданной датой. Полученная разница
переводится из миллисекунд в секунды, минуты, часы и дни.

В зависимости от количества прошедшего времени функция возвращает строку с
соответствующим описанием: секунды, минуты, часы или дни назад.

Для минут, часов и дней также учитывается правильное склонение слов. Например:
"1 минуту назад", "2 минуты назад", "5 минут назад", "1 час назад", "2 часа
назад", "5 часов назад", "1 день назад", "3 дня назад".

## Запуск

Импортируйте именованный `export` из `solution.js` как ES module.
