# Лабораторная работа 4

## Задание

Создать класс `Travel` с полями:

- `id` — уникальный номер путешествия (число);
- `travelerName` — имя путешественника (строка);
- `visitedCountries` — массив посещённых стран (строки).

Реализовать методы:

- `addCountry(country)` — добавить страну;
- `removeCountry(country)` — удалить страну;
- геттер `visitedCount` — получить количество посещённых стран.

Для массива путешествий реализовать функции:

- группировки путешествий по количеству посещённых стран;
- получения уникального списка всех посещённых стран;
- поиска путешествий, включающих заданную страну;
- группировки путешественников по странам;
- получения путешественников, посетивших более `N` стран.

Реализовать пользовательский интерфейс с карточками путешествий, содержащими имя
путешественника, ID, список посещённых стран и их количество. Добавить
возможность создания и удаления путешествий, а также добавления и удаления
стран.

Операции добавления и удаления выполняются асинхронно через `Promise` и
`setTimeout`. Состояние списка путешествий сохраняется в `localStorage` и
восстанавливается после перезагрузки страницы.

## Реализация

В файле `model.js` реализован класс `Travel`. Конструктор класса принимает `id`,
`travelerName` и массив `visitedCountries`. Метод `addCountry` добавляет новую
страну, если её ещё нет в списке, метод `removeCountry` удаляет указанную
страну, а геттер `visitedCount` возвращает количество посещённых стран.

В файле `main.js` реализована основная логика приложения: загрузка и
восстановление путешествий из `localStorage`, создание карточек путешествий,
добавление и удаление путешествий, а также добавление и удаление стран.

Для работы с коллекцией путешествий реализованы пять функций:

- `groupByVisitedCount()` — группирует путешествия по количеству посещённых
  стран;
- `getUniqueCountries()` — возвращает уникальный список всех посещённых стран;
- `getTravelsByCountry(country)` — возвращает путешествия, включающие заданную
  страну;
- `groupTravelersByCountry()` — группирует путешественников по посещённым
  странам;
- `getTravelersWithMoreThanNCountries(n)` — возвращает путешественников,
  посетивших более `N` стран.

Добавление и удаление данных выполняется асинхронно с помощью `Promise` и
`setTimeout`. После изменения массива путешествий данные сохраняются в
`localStorage`, после чего интерфейс перерисовывается.

В `index.html` реализована структура пользовательского интерфейса с полями для
ID путешествия, имени путешественника и страны, а также кнопками добавления и
удаления путешествий и стран.

В `styles.css` реализовано оформление страницы, элементов управления и карточек
путешествий.
