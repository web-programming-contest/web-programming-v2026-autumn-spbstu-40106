# Лабораторная работа 3

## Задание

Задача 3. Реализуйте функцию `findEquilibriumIndex(arr)`, которая находит
индекс, где сумма левой и правой части массива равна.

## Реализация

Решение оформлено в виде ES-модуля с именованным экспортом функции
`findEquilibriumIndex`.

- Сначала вычисляется полная сумма всех элементов массива `totalSum`.
- В цикле поддерживается сумма элементов слева `leftSum`, а сумма справа
  вычисляется как `totalSum - leftSum - arr[i]`.
- При равенстве левой и правой сумм возвращается текущий индекс (первый
  найденный).
- Если индекс не найден или входные данные некорректны, возвращается `-1`.
- Входной массив не мутируется. Временная сложность: $O(n)$, пространственная:
  $O(1)$.
