# Лабораторная работа 2

## Задание

Задача 2. Написать функцию `findLongestPalindrome(str)`, которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

Решение оформлено в виде ES-модуля с именованным экспортом функции
`findLongestPalindrome`. Алгоритм использует подход «расширение от центра»
(expand around center):

- Перебираются все возможные центры палиндромов (одиночные символы для нечётной
  длины и пары символов для чётной).
- Для каждого центра границы раздвигаются во внешние стороны до тех пор, пока
  символы совпадают.
- Сохраняются смещение и длина наибольшей найденной подстроки.
- Временная сложность: $O(n^2)$, пространственная сложность: $O(1)$.
