# Лабораторная работа 1

## Задание

Вариант 39. Создать форму регистрации по образцу.

Форма содержит поля имени, электронной почты, телефона, пароля, повторного ввода
пароля и кнопку «Регистрация».

Требования:

- ширина формы — 400px;
- внутренний отступ — 8px;
- цвет кнопки — #0056ff;
- цвет кнопки при наведении — #417ffb.

## Реализация

Разметка находится в index.html, оформление — в styles.css.

Для формы использован элемент form, для полей — input с типами text, email, tel
и password. Элементы расположены вертикально с помощью Flexbox.

Свойство box-sizing: border-box включает внутренние отступы в ширину формы.
Свойство max-width: 100% позволяет форме помещаться на узком экране.

Для кнопки реализовано состояние hover, для полей и кнопки — focus-visible. Поля
имеют доступные названия через aria-label.

Работа реализует внешний вид формы. Серверная регистрация и проверка совпадения
паролей не реализованы.

## Запуск

Откройте index.html в браузере или через расширение Live Server в VS Code.
