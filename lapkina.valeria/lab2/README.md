# Лабораторная работа 2

## Задание

Вариант 39. Реализовать функцию hexToRgb, которая преобразует цвет из полной
HEX-строки #RRGGBB в строку rgb(R, G, B).

Пример: #FF0000 преобразуется в rgb(255, 0, 0).

## Реализация

В файле solution.js реализована функция hexToRgb с именованным экспортом.

Сначала проверяются тип аргумента и формат строки: символ # и ровно шесть
шестнадцатеричных цифр. Допускаются прописные и строчные буквы A–F. При
некорректном вводе выбрасывается TypeError.

Метод slice выделяет три пары символов: красную, зелёную и синюю составляющие.
Number.parseInt с основанием 16 преобразует каждую пару в число от 0 до 255.

Функция возвращает строку rgb(R, G, B) с пробелами после запятых. Поддерживаются
чёрный цвет #000000, белый #FFFFFF и ведущие нули.

## Запуск

Из корня репозитория выполните:

```bash
node --input-type=module -e 'import { hexToRgb } from "./lapkina.valeria/lab2/solution.js"; console.log(hexToRgb("#FF0000"));'
```

Ожидаемый результат:

```text
rgb(255, 0, 0)
```
