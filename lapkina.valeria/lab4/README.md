# Лабораторная работа 4

## Задание

Вариант 39. Курсы и студенты.

Создать класс Course с полями courseId, title и students. Реализовать методы
addStudent, removeStudent и getter studentCount.

Реализовать пять функций работы с коллекцией курсов: группировку по количеству
студентов, получение уникальных студентов, поиск курсов студента, группировку
студентов по курсам и поиск курсов с максимальным количеством студентов.

Создать интерфейс добавления и удаления курсов и студентов. Операции должны
выполняться асинхронно через Promise и setTimeout. Состояние должно сохраняться
в localStorage и восстанавливаться после перезагрузки страницы.

## Реализация

Модель отделена от пользовательского интерфейса:

- model.js — класс Course и пять именованных функций;
- main.js — обработка событий, операции с DOM и localStorage;
- index.html — структура страницы и форма создания курса;
- styles.css — оформление и адаптация к узким экранам.

Экспортируемые функции:

- groupCoursesByStudentCount — объект с группами курсов по количеству студентов;
- getUniqueStudents — массив уникальных студентов по ID;
- findCoursesByStudent — массив курсов студента с заданным ID;
- groupStudentsByCourse — объект со списками студентов по ID курса;
- findLargestCourses — массив курсов с максимальным числом студентов.

Функции коллекций не изменяют входные данные. Для пустой коллекции функции
группировки возвращают пустой объект, остальные функции — пустой массив.

Повторное добавление студента с тем же ID в один курс запрещено. Один студент
может присутствовать в нескольких курсах. При равенстве максимального количества
студентов возвращаются все соответствующие курсы.

Все операции добавления и удаления в интерфейсе проходят через Promise и
setTimeout с задержкой 300 мс. На время операции кнопки блокируются.

После изменения данных обновляются localStorage и DOM без перезагрузки страницы.
Данные сохраняются под ключом lapkina.valeria.lab4.courses. При загрузке обычные
объекты из JSON преобразуются в экземпляры Course.

Пользовательский текст добавляется через textContent. Ошибки ввода и сохранения
отображаются на странице.

## Запуск

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Открыть:

http://localhost:8000/lapkina.valeria/lab4/

Для работы ES-модулей страницу нужно открывать через локальный сервер.

Порядок ручной проверки:

1. Создать курс с уникальным ID и названием.
2. Добавить студента и проверить количество студентов.
3. Попробовать повторно добавить студента с тем же ID.
4. Перезагрузить страницу и проверить сохранение данных.
5. Удалить студента и убедиться, что после перезагрузки он не появляется снова.
6. Удалить курс и проверить, что после перезагрузки он отсутствует.
7. Проверить страницу на узком экране.
