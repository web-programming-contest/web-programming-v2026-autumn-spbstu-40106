# Лабораторная работа 3

## Задание

Вариант 39. Реализовать функцию countOccurrences(arr), которая возвращает объект
с количеством вхождений каждого элемента массива.

Ключи результата — строковые представления элементов, значения — счётчики.

Пример: [1, 2, 1] преобразуется в {"1": 2, "2": 1}.

## Реализация

В файле solution.js реализована функция countOccurrences с именованным
экспортом.

Функция перебирает массив циклом for...of. Каждый элемент преобразуется в строку
с помощью String. Счётчики хранятся в Map: при первом появлении ключ получает
значение 1, при повторных появлениях значение увеличивается.

Object.fromEntries преобразует Map в обычный объект, который возвращается из
функции. Исходный массив не изменяется.

Для пустого массива возвращается пустой объект. Число 1 и строка "1" учитываются
вместе, поскольку имеют одинаковое строковое представление. Ключи "**proto**" и
"constructor" также обрабатываются как обычные значения.

## Запуск

Из корня репозитория выполните:

```bash
node --input-type=module -e 'import { countOccurrences } from "./lapkina.valeria/lab3/solution.js"; console.log(JSON.stringify(countOccurrences([1, 2, 1])));'
```

Ожидаемый результат:

```text
{"1":2,"2":1}
```
