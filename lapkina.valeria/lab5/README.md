# Лабораторная работа 5

## Задание

Вариант 39. Создать корзину книг на React.

Требуется вывести каталог книг с кнопками добавления в корзину. Повторное
добавление книги увеличивает количество экземпляров. В корзине можно увеличивать
количество и удалять позиции. Под корзиной отображается общая стоимость. Каталог
и корзина разделены горизонтальной линией.

## Реализация

Приложение написано на JavaScript с использованием React и Vite.

Компоненты:

- App — хранит состояние корзины и рассчитывает итоговую стоимость;
- BookCard — отображает книгу каталога и кнопку добавления;
- CartItem — отображает позицию корзины и кнопки управления.

Состояние корзины хранится в useState как массив объектов с полями bookId и
quantity. Обновления выполняются без изменения предыдущего массива, с
использованием map, filter и spread.

Книги идентифицируются по ID. Повторное добавление увеличивает количество, не
создавая вторую строку той же книги. Кнопка удаления удаляет позицию целиком.

Дополнительно реализована кнопка уменьшения количества на один. При уменьшении
количества до нуля позиция удаляется из корзины.

Цены хранятся в копейках, а итоговая стоимость вычисляется через reduce. Для
отображения рублей используется Intl.NumberFormat.

Добавлены обязательные data-testid: app, book-card, cart-add, cart-list,
cart-item, cart-total.

Интерфейс адаптируется к узким экранам. Корзина хранится в памяти приложения и
очищается после перезагрузки. Сохранение в localStorage условием этой задачи не
требуется.

## Запуск

Из каталога лабораторной:

```bash
npm install --package-lock=false
npm run dev
```

Открыть адрес, который выведет Vite в терминале.

Проверка производственной сборки:

```bash
npm run build
```

Проверка сценария:

1. Добавить «Маленького принца»: количество 1, сумма 450 рублей.
2. Добавить эту книгу повторно: одна позиция, количество 2, сумма 900 рублей.
3. Добавить «Алису в Стране чудес»: две позиции, всего 3 книги, сумма 1520
   рублей.
4. Увеличить количество «Маленького принца» кнопкой +1: сумма 1970 рублей.
5. Удалить «Маленького принца»: остаётся «Алиса», сумма 620 рублей.
6. Удалить оставшуюся книгу: пустая корзина, сумма 0 рублей.
