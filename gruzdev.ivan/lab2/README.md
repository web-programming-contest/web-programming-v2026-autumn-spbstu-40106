# Лабораторная работа 2

## Задание

Вариант 38. Сделать функцию, которая параметром получает дату, а возвращает знак
зодиака, соответствующий этой дате.

## Реализация

Функция `getZodiacSign` принимает объект `Date` и возвращает русское название
знака зодиака с заглавной буквы. Массив `ZODIAC_SIGNS` хранит для каждого знака
месяц и день верхней границы периода. Метод `find` возвращает первый знак, чья
верхняя граница не раньше переданной даты. Козерог занимает два интервала (конец
декабря и начало января), поэтому встречается в массиве дважды.
