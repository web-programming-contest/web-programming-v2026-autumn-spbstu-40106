# Лабораторная работа 5

## Задание

Вариант 38. Создать список книг в магазине и добавить расположенную справа
вверху кнопку переключения светлой и тёмной темы. Переключение реализовать с
помощью React Context API; для цветов светлой темы подобрать альтернативные
цвета тёмной темы. Дизайн-библиотеки не используются.

## Реализация

Приложение написано на React. `ThemeProvider` хранит выбранную тему и передаёт
её вместе с функцией переключения через `ThemeContext`. Состояние темы
сохраняется в `localStorage` и восстанавливается при следующем открытии
страницы. Компоненты магазина, кнопки темы и списка книг находятся в
`src/main.jsx`.

Для оформления используются CSS-переменные: светлая и тёмная темы задают
собственные цвета фона, текста, карточек, границ и акцентов. Каталог содержит
шесть книг с локальными CSS-обложками, названием, автором, жанром, описанием и
ценой. Сторонние дизайн-библиотеки и внешние ресурсы не подключаются.

## Запуск

Из каталога `gruzdev.ivan/lab5` выполнить:

```bash
npm install
npm run dev
```

Затем открыть в браузере адрес, который выведет Vite.
