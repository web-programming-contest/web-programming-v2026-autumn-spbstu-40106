# Лабораторная работа 4

## Задание

Вариант 38. Создать класс Game с полями title, platforms, releaseYear и методами
addPlatform/removePlatform, геттером platformCount. Реализовать пять функций
работы с массивом игр: группировка по году выпуска, уникальные платформы, игры
на заданной платформе, группировка по числу платформ, игры после заданного года.
Реализовать интерфейс с карточками игр, кнопками добавления/удаления игр и
платформ, формой создания игры, асинхронными операциями через setTimeout и
сохранением в localStorage.

## Реализация

Класс `Game` в `model.js` хранит поля через приватные свойства и предоставляет
геттеры на чтение, а также методы `addPlatform`/`removePlatform` для управления
списком платформ. Пять именованных функций коллекций (`groupGamesByReleaseYear`,
`getUniquePlatforms`, `findGamesByPlatform`, `groupGamesByPlatformCount`,
`findGamesReleasedAfter`) принимают массив игр и не изменяют исходный массив.
`main.js` реализует интерфейс: форма добавления игры, карточки с кнопками
управления платформами и удаления, асинхронные операции через `Promise` +
`setTimeout`, сохранение и восстановление состояния через `localStorage`.

## Запуск

Открыть index.html в браузере — файл самодостаточен и не требует сборки или
сервера.
