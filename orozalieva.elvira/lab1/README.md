# Лабораторная работа 1

## Задание

Создать форму регистрации с полями Имя, Фамилия, Пол (radio) и Владение языками
(checkbox). Использовать Grid или Flexbox для разделения на две половины.

## Реализация

Форма сверстана с использованием HTML5 и CSS Grid. Для выравнивания чекбоксов
использован Flexbox. Стили вынесены в отдельный файл styles.css.

## Запуск

Открыть файл index.html в браузере.
