# Лабораторная работа 3

## Задание

Реализовать функцию findMedian(arr), которая вычисляет медиану числового
массива.

## Реализация

Функция создает копию массива, сортирует её по возрастанию. В зависимости от
четности длины массива возвращает либо центральный элемент, либо среднее
арифметическое двух центральных элементов.

## Запуск

Запустить функцию можно в любом окружении, поддерживающем JavaScript.
