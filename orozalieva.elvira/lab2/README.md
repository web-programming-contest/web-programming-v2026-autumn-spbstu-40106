# Лабораторная работа 2

## Задание

Написать функцию findMissingNumber(arr), находящую пропущенное число в массиве
целых чисел от 1 до N (одно пропущено).

## Реализация

Функция использует математическую формулу суммы арифметической прогрессии.
Вычисляется ожидаемая сумма всех чисел от 1 до N, из нее вычитается фактическая
сумма элементов массива. Разница является пропущенным числом.

## Запуск

Запустить функцию можно в любом окружении, поддерживающем JavaScript (Node.js
или браузер).
