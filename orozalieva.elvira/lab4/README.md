# Лабораторная работа 4

## Задание

Создать класс BlogPost и функции для работы с массивом постов. Реализовать
интерактивный интерфейс с добавлением/удалением постов, тегов и комментариев,
асинхронностью и сохранением в localStorage.

## Реализация

Модель вынесена в model.js. Интерфейс и логика работы в main.js. Добавление и
удаление происходит асинхронно через Promise и setTimeout. Состояние сохраняется
в localStorage.

## Запуск

Открыть index.html в браузере.
