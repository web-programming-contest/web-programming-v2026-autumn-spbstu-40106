# Лабораторная работа 5

## Задание

Создать простой калькулятор с базовыми арифметическими операциями и
дополнительными функциями (очистка, проценты, смена знака). Отображение ввода и
результата.

## Реализация

Приложение написано на React с использованием Vite. Состояние калькулятора
управляется через хуки useState. Реализованы базовые операции (+, -, *, /),
очистка (C), вычисление процента (%) и смена знака (+/-). Интерфейс сверстан с
помощью CSS Grid.

## Запуск

Для запуска необходимо выполнить `npm install`, а затем `npm run dev` в папке
lab5.
