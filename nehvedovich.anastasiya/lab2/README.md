# Лабораторная работа 2

## Задание

Вариант 38. Сделайте функцию, которая параметром будет получать дату, а
возвращать знак зодиака, соответствующий этой дате.

## Реализация

Функция "getZodiacSign" берет данные из "Date" и возвращает знак зодиака,
соответствующий условиям month & day. month & day берут данные дня и месяца и
сравнивают с условием попадания в диапазон первого, либо второго месяца. Если
одно из условий совпадает, мы увидим нужный знак зодиака.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
