# Лабораторная работа 4

## Задание

Вариант 38. Создать класс `Game` с полями `title`, `platforms` и `releaseYear`.
Реализовать методы добавления и удаления платформы и геттер количества платформ.

Для массива игр реализовать функции:

- группировки игр по году выпуска;
- получения списка уникальных платформ;
- поиска игр по заданной платформе;
- группировки игр по количеству платформ;
- поиска игр, выпущенных после заданного года.

Реализовать пользовательский интерфейс с карточками игр, добавлением и удалением
игр и платформ. Операции добавления и удаления выполняются асинхронно через
`Promise` и `setTimeout`. Состояние списка игр сохраняется в `localStorage` и
восстанавливается после перезагрузки страницы.

## Реализация

В `model.js` реализован класс `Game` и пять функций работы с коллекцией игр. В
`main.js` реализованы работа с DOM, асинхронное добавление и удаление,
перерисовка интерфейса и сохранение состояния в `localStorage`.

## Запуск

Откройте `index.html` через локальный HTTP-сервер, например Live Server в VS
Code.
