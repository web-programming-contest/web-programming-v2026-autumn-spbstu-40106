# Лабораторная работа 3

## Задание

Вариант 38. Реализуйте функцию sortByFrequency(arr), которая сортирует элементы массива по частоте встречаемости. 

## Реализация

В функции "sortByFrequency(arr)" задается значение "frequency". Мы задаем цикл для прохода по всему массиву и получаем значение item: если встречается новое число, мы обозначаем его как 0, а если значение повторяется - увеличиваем счетчик. Чтобы не изменять входные значения производится копирование массива result = [...arr], а дальше сортировка по убыванию частоты. Если разница между b & a - положительное число, b будет идти раньше a. 

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
