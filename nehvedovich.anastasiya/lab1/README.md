# Лабораторная работа 1

## Задание

Вариант 38. Создать «хлебные крошки». «Хлебные крошки» должны удовлетворять
следующим требованиям:

- Основа структуры – список;
- Элементы списка – ссылки;
- Последний элемент списка – span;
- Цвет ссылок - #0056ff;
- Ссылка при наведении подчеркивается снизу;
- Цвет span-элемента - #333;
- Стрелки между элементами реализованы через псевдо-элемент after.

## Реализация

Хлебные крошки состоят из одного род. элемента <ul> и 3-х элементов-детей <li>.
"Каталог" и "Главная" - ссылки <a> с свойствами color (цвет),
text-decoration:none (убираем постоянное базовое нижнее подчеркивание) и
text-decoration:underline (добавляем нижнее подчеркивание). Чтобы подчеркивание
было только при наведении, к <a> добавляем псевдокласс hover; "Техника" -
элементом <span> и color. К списку добавлен ">" посредством условия
not(:last-child) и псевдоэлемента after.

## Запуск

Откройте `index.html` в браузере.
