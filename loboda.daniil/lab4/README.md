# Лабораторная работа 4

## Задание

Вариант 15 «Путешествия». Требуется реализовать класс `Travel`, пять функций для
обработки массива путешествий и интерфейс для добавления и удаления путешествий
и стран. Данные должны сохраняться в `localStorage` и восстанавливаться после
перезагрузки страницы.

## Реализация

### Файлы

| Файл         | Назначение                                                       |
| ------------ | ---------------------------------------------------------------- |
| `model.js`   | Класс `Travel` и функции обработки массива путешествий           |
| `main.js`    | Обработчики интерфейса, асинхронные операции и сохранение данных |
| `index.html` | Формы, список путешествий и шаблон карточки                      |
| `styles.css` | Оформление страницы и расположение элементов на разных экранах   |

### 4.1. Класс `Travel`

У путешествия есть числовой `id`, строка `travelerName` и массив строк
`visitedCountries`.

- Конструктор создаёт копию переданного массива стран.
- `addCountry(country)` добавляет страну, если её ещё нет в списке.
- `removeCountry(country)` удаляет указанную страну.
- Геттер `visitedCount` возвращает количество посещённых стран.

### 4.2. Работа с массивом путешествий

Все функции экспортируются из `model.js`.

| Функция                                    | Результат                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------- |
| `groupTravelsByCountryCount(travels)`      | `Map`, где ключ — количество стран, а значение — массив объектов `Travel` |
| `getUniqueCountries(travels)`              | Массив всех посещённых стран без повторов                                 |
| `findTravelsByCountry(travels, country)`   | Массив путешествий, включающих указанную страну                           |
| `groupTravelersByCountry(travels)`         | `Map`, где ключ — страна, а значение — массив объектов `Travel`           |
| `findTravelsAboveCountryCount(travels, n)` | Массив объектов `Travel`, у которых `visitedCount > n`                    |

Функции создают новые коллекции. Группировки и фильтрация используют ссылки на
исходные объекты `Travel`.

### 4.3. Интерфейс

- Путешествие создаётся по имени и уникальному положительному целочисленному ID.
  Проверка уникальности выполняется в `main.js`.
- Карточка показывает имя путешественника, ID, список стран и их количество.
- В карточке можно добавить или удалить страну и удалить путешествие.
- Все операции добавления и удаления выполняются через `Promise` и `setTimeout`
  с задержкой 350 мс. На время операции поля и кнопки блокируются.
- После изменения список сохраняется в `localStorage`, затем карточки
  обновляются. При открытии страницы сохранённые записи преобразуются обратно в
  экземпляры класса `Travel`.

Пробелы по краям введённых значений удаляются. Названия стран сравниваются с
учётом регистра.

## Запуск

Откройте терминал в папке `loboda.daniil/lab4` и запустите локальный
HTTP-сервер.

```powershell
python -m http.server 8000
```

Откройте страницу в браузере. [http://localhost:8000](http://localhost:8000)

Для запуска достаточно Python и браузера. Чтобы остановить сервер, нажмите
`Ctrl+C`.

### Проверка интерфейса

1. Создайте путешествие с ID `1` и именем `Анна`.
2. Добавьте страны `Россия` и `Грузия`. Счётчик в карточке покажет `2`.
3. Попробуйте повторно добавить `Россия` и создать ещё одно путешествие с ID
   `1`. В обоих случаях появится сообщение о повторе.
4. Удалите одну страну. Проверьте, что список и счётчик обновились.
5. Перезагрузите страницу. Карточка и оставшаяся страна восстановятся.
6. Добавьте ещё одну страну, чтобы проверить работу методов класса после
   восстановления данных.
7. Удалите путешествие и перезагрузите страницу. Если это была единственная
   карточка, список останется пустым.

Сохранённые данные доступны при повторном открытии приложения в том же браузере
по тому же адресу и порту.
