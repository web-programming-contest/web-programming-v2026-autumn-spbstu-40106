# Лабораторная работа 3

## Задание

Вариант 15. Реализовать функцию `moveZerosToEnd(arr)`, которая перемещает все
числовые нули в конец массива и сохраняет порядок остальных элементов.

## Реализация

Функция `moveZerosToEnd` находится в `solution.js` и экспортируется по имени.
Она дважды перебирает входной массив. При первом проходе записывает в новый
массив элементы, отличные от числового нуля. При втором проходе добавляет нули.

| Входной массив          | Результат               |
| ----------------------- | ----------------------- |
| `[0, 3, 0, 2]`          | `[3, 2, 0, 0]`          |
| `[1, 2, 3]`             | `[1, 2, 3]`             |
| `[0, 0]`                | `[0, 0]`                |
| `[]`                    | `[]`                    |
| `[0, '0', false, null]` | `['0', false, null, 0]` |

## Запуск

Из корня репозитория выполните команду.

```powershell
node --input-type=module -e "import { moveZerosToEnd } from './loboda.daniil/lab3/solution.js'; console.log(moveZerosToEnd([0, 3, 0, 2]));"
```

Ожидаемый результат — `[3, 2, 0, 0]`.
