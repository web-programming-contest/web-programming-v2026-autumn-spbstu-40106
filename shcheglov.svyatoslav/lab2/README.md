# Лабораторная работа 2

## Задание

Вариант 35. Написать функцию `findMissingNumber(arr)`, находящую пропущенное
число в массиве целых чисел от 1 до N (одно число пропущено).

## Реализация

Решение находится в файле `solution.js`. Функция `findMissingNumber` вычисляет
сумму всех чисел от 1 до N по формуле `N * (N + 1) / 2`, где `N` — длина массива
плюс один. Затем из этой суммы вычитается сумма элементов массива, и разность
равна пропущенному числу.

## Запуск

Импортируйте именованный export `findMissingNumber` из файла `solution.js` как
ES module.
