# Лабораторная работа 3

## Задание

Вариант 35. Реализовать функцию `findMedian(arr)`, которая вычисляет медиану
числового массива.

## Реализация

Решение находится в файле `solution.js`. Функция `findMedian` сортирует копию
массива по возрастанию. Если количество элементов нечётное, медианой является
средний элемент, если чётное — среднее арифметическое двух средних элементов.
Для пустого массива функция возвращает `null`.

## Запуск

Импортируйте именованный export `findMedian` из файла `solution.js` как ES
module.
