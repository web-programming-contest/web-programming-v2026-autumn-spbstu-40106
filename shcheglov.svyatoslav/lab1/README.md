# Лабораторная работа 1

## Задание

Вариант 35. Создать постраничную навигацию по образцу из задания. Элементы
навигации должны находиться по центру, текст внутри элементов выровнен по центру
по двум осям, фон активного элемента отличается от остальных, фон элементов при
наведении изменяется.

## Реализация

Для решения использованы семантические теги:

- `<nav>` — контейнер постраничной навигации
- `<a>` — элементы навигации: «<», «1», «2», «3», «>»

Активный элемент имеет класс `pagination-link-active`. Стилизация выполнена в
файле `styles.css`.

## Запуск

Откройте `index.html` в браузере.
