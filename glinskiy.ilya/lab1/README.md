# Лабораторная работа 1

## Задание

Вариант 34. Создать меню блюд, используя неупорядоченный список. Меню должно
удовлетворять следующим требованиям:

- Каждый пункт меню (`<li>`) состоит из названия блюда и цены;
- Название блюда должно располагаться в левом краю контейнера, а цена должна
  прижиматься к правому краю, независимо от длины названия блюда (необходимо
  использовать Flexbox или Grid);
- Каждый пункт меню должен занимать всю ширину контейнера `<ul>`;
- Ширина контейнера `<ul>` - 400px;
- Между элементами списка должен быть вертикальный отступ 16px.
- Элементы списка должны быть разделены сплошной черной линией, толщина которой
  составляет 1px.

## Реализация

Меню состоит из одного элемента - `<ul>`, и его детей - `<li>`. Внутри каждого
элемента списка есть два `<span>` - название блюда и цена. На каждом `<li>`
висит `display: flex` и `justify-content: space-between`, благодаря которым
название и цена блюда расположены по разным сторонам.

## Запуск

Откройте `index.html` в браузере.
