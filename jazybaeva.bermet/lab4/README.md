# Лабораторная работа 4

## Задание

Вариант 15. Создать класс `Travel` с полями `id`, `travelerName`,
`visitedCountries`. Реализовать методы `addCountry`, `removeCountry`, геттер
`visitedCount`. Реализовать функции работы с коллекцией: группировка по
количеству стран, уникальный список стран, фильтр по стране, группировка по
странам, фильтр по N странам.

Создать UI: карточки путешествий, формы добавления путешествия и страны, кнопки
удаления. Все операции — асинхронно через Promise + setTimeout. Сохранять
состояние в localStorage.

## Реализация

Модель в `model.js`: класс `Travel` и функции `groupByVisitedCount`,
`getAllCountries`, `filterByCountry`, `groupTravelersByCountry`,
`filterByMinCountries`. Все экспортируются именованно.

UI в `main.js`: рендеринг карточек, обработка форм, асинхронная обёртка
`asyncAction` (Promise + setTimeout), сохранение в localStorage после каждого
действия, восстановление при загрузке.

Стили в `styles.css`, разметка в `index.html`. Использованы `data-testid` для
автотестов.

## Запуск

Открыть `index.html` в браузере. Дополнительные инструменты и сборка не
требуются.
