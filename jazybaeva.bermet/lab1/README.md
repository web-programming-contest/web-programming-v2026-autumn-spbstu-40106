# Лабораторная работа 1

## Задание

Вариант 15. Отцентрировать блок текста и изображение внутри контейнера,
используя разные методы центрирования:

- используя Flexbox для контейнера;
- используя абсолютное позиционирование для текста и изображения.

Изображение должно быть размещено в правом верхнем углу контейнера. Текст должен
автоматически обтекать изображение.

## Реализация

Работа состоит из HTML-страницы `index.html` и подключённого файла стилей
`styles.css`. На странице размещены два контейнера, демонстрирующих разные
способы центрирования.

Вариант 1 — Flexbox + float. Контейнеру заданы `display: flex`,
`align-items: center` и `justify-content: center`, что центрирует содержимое по
обеим осям. Изображение прижато вправо через `float: right` с отступом, поэтому
текст автоматически обтекает его.

Вариант 2 — абсолютное позиционирование. Контейнеру задан `position: relative`,
изображению — `position: absolute` с `top` и `right`, что закрепляет его в
правом верхнем углу. Текст центрируется через Flexbox, а чтобы он не наезжал на
изображение, у текстового блока задан `padding-right`.

Inline-стили не используются, все стили вынесены в отдельный файл.

## Запуск

Открыть файл `index.html` в любом современном браузере. Дополнительные
инструменты и сборка не требуются.
