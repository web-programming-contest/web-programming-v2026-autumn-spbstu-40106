# Лабораторная работа 3

## Задание

Вариант 15. Реализовать функцию `moveZerosToEnd(arr)`, которая перемещает все
нули в конец массива, сохраняя порядок остальных элементов.

## Реализация

Решение находится в файле `solution.js` и представляет собой ES-модуль с
единственным именованным экспортом `moveZerosToEnd`.

Функция `moveZerosToEnd(arr)` работает за один проход по массиву: сначала
собирает все ненулевые элементы в отдельный массив и подсчитывает количество
нулей, затем добавляет нули в конец. Исходный массив не изменяется.

Сравнение с нулём строгое (`=== 0`), чтобы не отсеивать `false`, `null`,
`undefined` и пустые строки, которые при нестрогом сравнении приводились бы к
нулю.

## Запуск

Функцию можно импортировать в любом JavaScript-окружении, поддерживающем
ES-модули:

```javascript
import {moveZerosToEnd} from './solution.js';

console.log(moveZerosToEnd([0, 1, 0, 3, 12]));
console.log(moveZerosToEnd([0, 0, 1]));
console.log(moveZerosToEnd([1, 2, 3]));
```
