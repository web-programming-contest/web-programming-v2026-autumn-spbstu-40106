# Лабораторная работа 5

## Задание

Вариант 15. Создать приложение для заметок с возможностью создания,
редактирования, удаления заметок, группировки по тегам, поиска по содержимому и
фильтрации.

## Реализация

Приложение на React. Используются хуки `useState` и `useEffect`. Заметки
сохраняются в `localStorage` и восстанавливаются при загрузке. Реализованы формы
добавления, поиск, фильтрация по тегу, удаление. Корневой элемент имеет
`data-testid="app"`.

## Запуск

```bash
cd jazybaeva.bermet/lab5
npm install
npm run dev
```
