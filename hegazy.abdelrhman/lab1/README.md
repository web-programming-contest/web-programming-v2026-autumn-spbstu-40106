# Лабораторная работа 1

## Задание

Вариант 13. Создать блок с текстом произвольной длины. С помощью CSS реализовать
механизм, скрывающий текст, если он превышает высоту 100px или 3 строки. Текст,
выходящий за лимит, должен обрезаться и заменяться многоточием (…). Шрифт текста
— Arial, размер — 16px.

## Реализация

Блок реализован с помощью CSS line-clamp: контейнер `.text-block` использует
`display: -webkit-box` вместе с `-webkit-line-clamp: 3` и
`-webkit-box-orient: vertical`, что ограничивает видимую область тремя строками
и автоматически добавляет многоточие. Дополнительно задан `max-height: 100px` и
`overflow: hidden` как ограничение по высоте. Шрифт и размер текста заданы через
`font-family: Arial` и `font-size: 16px`.

## Запуск

Откройте `index.html` в браузере — двойным кликом по файлу, либо через
расширение Live Server в VS Code (правый клик по файлу → "Open with Live
Server").
