# Лабораторная работа 2

## Задание

Вариант 13. Реализовать функцию, которая принимает дату в качестве параметра и
возвращает знак зодиака, соответствующий этой дате.

## Реализация

Функция `getZodiacSign(date)` принимает объект `Date` (или значение, пригодное
для создания `Date`). Знаки зодиака и границы дат хранятся в массиве
`ZODIAC_SIGNS`, где для каждого знака указан месяц и день его окончания. Функция
определяет месяц и день переданной даты и находит соответствующий знак,
возвращая его русское название с заглавной буквы. При некорректной дате
выбрасывается исключение.

## Запуск

Импортировать функцию из `solution.js` как ES-модуль и вызвать с объектом
`Date`, например:

import { getZodiacSign } from './solution.js'; console.log(getZodiacSign(new
Date('2000-05-15'))); // "Телец"
