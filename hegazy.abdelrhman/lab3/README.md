# Лабораторная работа 3

## Задание

Вариант 13. Реализовать функцию sortByFrequency(arr), которая сортирует элементы
массива по частоте встречаемости (более частые — впереди).

## Реализация

Функция `sortByFrequency(arr)` сначала подсчитывает количество вхождений каждого
элемента с помощью `Map`. Затем создаётся копия исходного массива и сортируется
по убыванию частоты элемента, используя посчитанные значения как ключ сравнения.
Исходный массив не изменяется.

## Запуск

Импортировать функцию из `solution.js` как ES-модуль и вызвать с массивом,
например:

import { sortByFrequency } from './solution.js'; console.log(sortByFrequency([1,
2, 2, 3, 3, 3])); // [3, 3, 3, 2, 2, 1]
