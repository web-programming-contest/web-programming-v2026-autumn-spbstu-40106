# Лабораторная работа 5

## Задание

Вариант 13. Создать простое чат-приложение на React с сохранением истории
сообщений в localStorage. Пользователь вводит имя, отправляет сообщения и видит
историю даже после перезагрузки страницы. Рядом с сообщением отображается имя
пользователя и дата/время, есть кнопка «Очистить чат».

## Реализация

Приложение состоит из компонента `App` (`src/App.jsx`) и точки входа
`src/main.jsx`. Сообщения хранятся в состоянии React (`useState`), начальное
значение загружается из `localStorage`, а при каждом изменении списка
`useEffect` сохраняет его обратно. Каждое сообщение содержит автора, текст и
время отправки. Кнопка «Очистить чат» удаляет всю историю. Корневой элемент
имеет `data-testid="app"`.

## Запуск

Из каталога lab5 выполнить:

npm install npm run dev

Затем открыть адрес, который выведет Vite (обычно http://localhost:5173).
