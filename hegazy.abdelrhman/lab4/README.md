# Лабораторная работа 4

## Задание

Вариант 13. Создать класс Game с полями title, platforms, releaseYear, методами
addPlatform, removePlatform и геттером platformCount. Реализовать функции для
массива игр: группировка по году выпуска, список уникальных платформ, поиск игр
по платформе, группировка по количеству платформ, поиск игр, выпущенных после
заданного года. Реализовать интерфейс с карточками игр, формой добавления,
кнопками добавления/удаления платформ и игр, асинхронными операциями через
Promise и setTimeout и сохранением данных в localStorage.

## Реализация

Модель находится в `model.js`: класс `Game` и функции `groupGamesByReleaseYear`,
`getUniquePlatforms`, `findGamesByPlatform`, `groupGamesByPlatformCount`,
`findGamesReleasedAfter`. Интерфейс находится в `main.js`: карточки игр
выводятся в `[data-testid="entity-list"]`, добавление и удаление выполняются
асинхронно через функцию `delay`, которая оборачивает `setTimeout` в `Promise`.
После каждого изменения список сохраняется в `localStorage` и интерфейс
перерисовывается; при загрузке страницы данные восстанавливаются.

## Запуск

Откройте `index.html` через расширение Live Server в VS Code (правый клик по
файлу → "Open with Live Server"). Модули ES требуют запуска через локальный
сервер.
