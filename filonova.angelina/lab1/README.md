# Лабораторная работа 1

## Задание

Вариант 10. Создать форму регистрации с полями имени, фамилии, выбора пола и
владения языками. Подписи должны располагаться слева, а поля ввода — справа. Для
размещения элементов использовать Grid или Flexbox.

## Реализация

В HTML создана форма с текстовыми полями для имени и фамилии, радиокнопками для
выбора пола и checkbox для выбора языков.

Поля формы размещены в две колонки с помощью CSS Grid Радиокнопки позволяют
выбрать только один вариант пола Checkbox позволяют выбрать несколько языков Для
всех элементов добавлены соответствующие подписи Добавлено адаптивное
отображение для небольших экранов

Стили вынесены в отдельный файл styles.css.

## Запуск

Откройте `index.html` в браузере.
