# Лабораторная работа 2

## Задание

Вариант 8. Реализовать функцию `countVowels(str)`, которая возвращает количество
гласных букв (a, e, i, o, u) в строке без учёта регистра.

## Реализация

Функция экспортируется под именем `countVowels`. Использовано регулярное
выражение `/[aeiou]/gi` для поиска всех вхождений без учета регистра.

## Запуск

Импортировать функцию как ES module:
`import { countVowels } from './solution.js';`
