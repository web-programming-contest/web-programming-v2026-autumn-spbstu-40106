# Лабораторная работа 5

## Задание

Вариант 8. Создать приложение для бронирования билетов на фильмы[cite: 1].
Приложение должно включать список фильмов (постер, название), форму бронирования
с валидацией данных и экран подтверждения бронирования[cite: 1]. Обязательные
поля формы и их валидация:

- Имя: не менее 2 символов[cite: 1].
- Email: любой допустимый формат электронной почты[cite: 1].
- Телефон: цифры, символ `+` в начале[cite: 1]. Дополнительные нестрогие поля:
  Дата сеанса, Время, Количество билетов, Тип билета[cite: 1].

## Реализация

Приложение написано на React с использованием сборщика Vite[cite: 3]. Логика
переключения между экранами (афиша, форма, успех) и хранение данных формы
реализованы через хук `useState`. Корневой узел разметки использует тег
`<main data-testid="app">` согласно публичному контракту CI[cite: 3]. Валидация
выполняется синхронно через объект `FormData` и регулярные выражения без
подключения сторонних библиотек. Для изоляции приложения и соблюдения требований
к работе без интернета[cite: 3], вместо внешних изображений постеров
используются эмодзи.

## Запуск

Перейдите в директорию лабораторной работы и установите зависимости:

```bash
npm install
```

Запустите сервер для разработки:

```bash
npm run dev
```
