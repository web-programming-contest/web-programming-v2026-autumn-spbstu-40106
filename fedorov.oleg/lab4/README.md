# Лабораторная работа 4

## Задание

Вариант 8[cite: 1].

1. Создать класс `Product` с полями id, name, categories, price; методами
   добавления/удаления категорий и геттером количества категорий[cite: 1].
2. Написать функции группировки, поиска уникальных категорий, фильтрации по цене
   и категориям[cite: 1].
3. Реализовать UI: карточки товаров, формы создания, кнопки удаления. Все
   операции добавления/удаления выполнять асинхронно через Promise +
   setTimeout(). Сохранять состояние в local storage[cite: 1].

## Реализация

Проект разделен на `model.js` (логика данных и именованные экспорты класса и
функций коллекций) и `main.js` (управление пользовательским интерфейсом)[cite:
3]. В UI реализованы необходимые атрибуты `data-testid` для списков, форм и
карточек согласно контракту[cite: 3]. Добавление и удаление элементов
инкапсулировано в `Promise` с задержкой в 500мс для имитации работы сети, после
чего происходит автоматическое обновление DOM[cite: 3]. При перезагрузке
страницы данные корректно восстанавливаются из `localStorage`[cite: 3].

## Запуск

Открыть файл `index.html` с помощью локального сервера (например, расширения
Live Server в VS Code), чтобы корректно работали ES-модули
(`<script type="module">`).
