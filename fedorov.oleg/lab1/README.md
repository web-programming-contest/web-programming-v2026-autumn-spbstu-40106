# Лабораторная работа 1

## Задание

Вариант 8. Сверстать флаг Японии, сам красный круг в центре сделать с помощью
position: absolute, разместив его точно по центру.

## Реализация

Использована семантическая HTML разметка. Центрирование круга выполнено через
position: absolute, top/left 50% и transform: translate(-50%, -50%).

## Запуск

Открыть файл `index.html` в любом современном браузере.
