# Лабораторная работа 3

## Задание

Вариант 8. Реализуйте функцию `shuffleArray(arr)`, которая перемешивает элементы
массива в случайном порядке[cite: 1].

## Реализация

Функция оформлена как именованный экспорт[cite: 3]. В основе логики лежит
алгоритм тасования Фишера-Йетса (Fisher-Yates) для обеспечения истинно
случайного распределения элементов. Чтобы удовлетворить требованиям к чистоте
функций, входной массив предварительно копируется поверхностно (shallow copy)
через spread-оператор (`[...arr]`), после чего перемешивается и
возвращается[cite: 3]. Мутация оригинального массива отсутствует[cite: 3].

## Запуск

Импортировать функцию через `import { shuffleArray } from './solution.js'`.
Передать в нее целевой массив в качестве аргумента.
